1. Explanatory Paragraph

When a user types a URL into a web browser (the client), the browser initiates a request-response cycle by sending a request over the internet using HTTP (Hypertext Transfer Protocol) or HTTPS (Hypertext Transfer Protocol Secure, which encrypts data for security). This request travels to a web server, which hosts the website files; if the site is a dynamic website, the server communicates with a database to fetch or update specific data and generate personalized content, whereas a static website simply returns pre-written HTML, CSS, and JavaScript files directly. Once processed, the server sends back an HTTP response containing the requested resources, which the browser then interprets and renders into the visual webpage displayed on your screen.

2. Guide to Complete Item #5 (DevTools Screenshot)

To capture the Network tab screenshot required for your submission:

Open Google Chrome and go to any website (e.g., https://google.com).

Open DevTools by pressing F12 (or Ctrl + Shift + I on Windows / Cmd + Option + I on Mac).

Click on the Network tab at the top of the DevTools panel.

Refresh the page (F5 or Ctrl + R) to capture all outgoing requests.

Take a screenshot of the Network tab showing the loaded requests, status codes, and file types, then attach it to your final submission.
